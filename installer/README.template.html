Install করার নিয়ম

Windows

  1. Premiere Pro খোলা থাকলে বন্ধ করুন।
  2. BunnysAudioSeparator-Setup-…exe file-এ double-click করুন।
  3. "Windows protected your PC" দেখালে More info চেপে Run anyway চাপুন।
  4. Install চাপুন, শেষ হলে Finish। Admin password লাগবে না।

Mac

  1. Premiere Pro বন্ধ করুন।
  2. .pkg file-এ double-click করুন।
  3. Block দেখালে System Settings → Privacy & Security এ যান, নিচের দিকে Open Anyway চাপুন, তারপর আবার .pkg খুলুন।
  4. নির্দেশনা অনুযায়ী Continue → Install চাপুন, Mac-এর password দিন।
Installer এখনো code-sign করা নেই, তাই Windows/Mac প্রথমবার সতর্ক করে। এটা স্বাভাবিক।

ব্যবহারের নিয়ম

  1. Premiere Pro চালু করে Window → Extensions → Bunnys Audio Separator খুলুন।
  2. Timeline-এ একটা clip select করুন (audio, audio-সহ video, অথবা nested sequence)।
  3. Mode বাছুন:
    • Music Stems — গান থেকে Vocals, Drums, Bass, Guitar, Piano, Other, Instrumental
    • Vocal · SFX · Music — ভিডিও/ফিল্ম থেকে কথা, sound effect, music, অথবা Background (কথা বাদে সব)
  4. যে stem-গুলো লাগবে সেগুলোতে tick দিন।
  5. Device: Auto (recommended) / GPU / CPU। Quality: Fast / Balanced (recommended) / Best।
  6. Separate selected clip চাপুন। প্রতিটা stem নতুন audio track-এ মূল clip-এর সাথে sync হয়ে বসবে।
  • প্রথমবার প্রতিটা mode-এর AI model নিজে থেকে একবার download হয় (internet লাগবে)।
  • Stem-গুলো project-এর পাশে Bunnys Stems folder-এ এবং Premiere-এর Bunnys Stems bin-এ থাকে।
  • Speed বদলানো বা reverse করা clip-ও কাজ করে — stem একই speed-এ বসে।
  • “Mute original clip” চালু করলে আলাদা করার পর মূল clip mute হয়ে যায়।

Uninstall করার নিয়ম

Windows

  1. Premiere Pro বন্ধ করুন।

  1. Premiere Pro বন্ধ করুন।
  2. Uninstall Bunnys Audio Separator.command এ right-click → Open → Open, তারপর Enter আর Mac-এর password দিন।

সমস্যা হলে

  • Extensions menu-তে নেই: Premiere পুরোপুরি বন্ধ করে আবার খুলুন। তবুও না এলে আবার install করুন।
  • “Could not download the AI model”: internet connection দেখে আবার চেষ্টা করুন।
  • ধীর চলছে: panel-এ “GPU acceleration ready” লেখা আছে কিনা দেখুন; Quality “Fast” দিন। GPU ছাড়া Vocal·SFX·Music mode বেশ সময় নেয়।
  • “Not enough empty audio tracks”: sequence-এ কয়েকটা খালি audio track যোগ করুন।

Install

Windows

  1. Close Premiere Pro.
  2. Double-click BunnysAudioSeparator-Setup-…exe.
  3. If “Windows protected your PC” appears, click More info → Run anyway.
  4. Click Install, then Finish. No admin rights needed.

macOS

  1. Quit Premiere Pro.
  2. Double-click the .pkg.
  3. If it is blocked, open System Settings → Privacy & Security, click Open Anyway, and open the .pkg again.
  4. Click Continue → Install and enter your Mac password.
The installers are not code-signed yet, so Windows/macOS show a warning the first time. That is expected.

How to use

  1. Start Premiere Pro and open Window → Extensions → Bunnys Audio Separator.
  2. Select a clip in the timeline (audio, video with audio, or a nested sequence).
  3. Pick a mode:
    • Music Stems — Vocals, Drums, Bass, Guitar, Piano, Other and Instrumental from songs
    • Vocal · SFX · Music — dialogue, sound effects, music, or Background (everything except the voice) from video and film audio
  4. Tick the stems you want.
  5. Device: Auto (recommended) / GPU / CPU. Quality: Fast / Balanced (recommended) / Best.
  6. Click Separate selected clip. Each stem lands on a new audio track, in sync with the original clip.
  • Each mode's AI model downloads once, automatically, the first time you use it (internet needed).
  • Stems are saved in a Bunnys Stems folder next to your project and in the Bunnys Stems bin.
  • Speed-changed and reversed clips are supported — stems are placed at the same speed.
  • “Mute original clip” mutes the source clip after separating.

Uninstall

Windows

  1. Close Premiere Pro.
  2. Double-click Uninstall Bunnys Audio Separator.bat and press any key.
  3. Or use Settings → Apps → Installed apps → Bunnys Audio Separator → Uninstall.

macOS

  1. Quit Premiere Pro.
  2. Right-click Uninstall Bunnys Audio Separator.command → Open → Open, press Enter and type your Mac password.

Troubleshooting

  • Not in the Extensions menu: fully quit and reopen Premiere Pro; reinstall if needed.
  • “Could not download the AI model”: check your internet connection and try again.
  • Slow: check that the panel says “GPU acceleration ready”, or choose Quality “Fast”. Without a GPU, Vocal · SFX · Music takes a while.
  • “Not enough empty audio tracks”: add a few empty audio tracks to the sequence.
